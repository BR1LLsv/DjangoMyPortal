# MyPortal (DjangoMyPortal)

## Что делает этот проект
MyPortal — это многофункциональный персональный веб-портал для пользователей. 

Основные возможности проекта:
* Авторизация и профиль: Регистрация, вход в систему, редактирование личных данных и информации «о себе».
* Менеджер задач (To-Do list): Создание заметок и задач, отметка их выполнения, удаление и фильтрация (все, активные, выполненные).
* Система личных сообщений: Внутренний чат для общения между зарегистрированными пользователями в реальном времени, с диалогами и счетчиком непрочитанных сообщений.
* Дашборд: Главная страница со сводной статистикой по задачам пользователя (всего, выполнено, осталось).

## В чём смысл проекта
Смысл проекта — создать единое удобное рабочее пространство («всё в одном»), которое объединяет инструменты для личной продуктивности (трекинг задач и статистика) и коммуникации (обмен сообщениями с другими пользователями) внутри одной системы.
